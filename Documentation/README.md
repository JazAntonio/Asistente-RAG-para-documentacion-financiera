# Descripción General de del Dataset Sintético de Documentación Financiera (Uso Educativo)

**Aviso de seguridad y uso**: Todos los documentos contenidos en este archivo son **completamente ficticios**, generados con fines educativos y de demostración técnica. No representan políticas reales de ninguna institución financiera, no contienen datos sensibles ni reproducen documentos internos existentes.

Este archivo contiene un resumen de los documentos financieros, diseñados con fines educativos y de demostración técnica.

## 1. Política de Otorgamiento de Crédito PYME
**Objetivo:** Establecer los lineamientos generales para la evaluación y otorgamiento de créditos a pequeñas y medianas empresas (PYMES), con el fin de promover el crecimiento sostenible del portafolio crediticio y mantener un nivel de riesgo controlado.

## 2. Política de Gestión de Riesgo Crediticio
**Introducción:** La gestión de riesgo crediticio es un componente esencial para la estabilidad financiera. Esta política define los principios generales para identificar, medir y mitigar riesgos asociados al otorgamiento de crédito.

## 3. Manual Operativo del Proceso de Crédito
**Propósito:** Describir paso a paso el proceso operativo para la recepción, análisis, aprobación y seguimiento de solicitudes de crédito.

## 4. Lineamientos Generales de Cumplimiento y PLD (Ficticio)
**Objetivo:** Establecer criterios generales para prevenir operaciones que pudieran representar riesgos legales o reputacionales.

## 5. Descripción de Productos de Crédito Empresarial
**Resumen:** Describe productos de crédito empresarial como Crédito Simple y Crédito Revolvente, detallando sus características y condiciones generales.

## 6. Preguntas Frecuentes para Ejecutivos de Cuenta
**Resumen:** Contiene preguntas frecuentes para ejecutivos de cuenta sobre documentos indispensables, tiempo de aprobación y excepciones.
